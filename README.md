# Drip Store - E-commerce Front-end

Este é o projeto final de Front-end da formação **Geração Tech 4.0**, uma iniciativa do **IEL Ceará** em parceria com a **Digital College**. 

O objetivo do projeto foi desenvolver uma aplicação web completa e responsiva de e-commerce, baseada no design "DRIP STORE" disponibilizado no Figma. A aplicação simula uma loja virtual real, consumindo dados de produtos através de uma API e gerenciando o estado do carrinho de compras.

🔗 **Link do Projeto Online:** [Em breve - Após o deploy]

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas e bibliotecas:

*   **React** (com Vite para build e desenvolvimento rápido)
*   **TypeScript** (Tipagem estática e segurança do código)
*   **Tailwind CSS** (Estilização ágil e responsiva)
*   **React Router DOM** (Navegação entre páginas SPA)
*   **Context API** (Gerenciamento de estado global do carrinho)
*   **React Icons** (Biblioteca de ícones)
*   **Fake Store API** (Consumo de dados reais de produtos para simular um backend)

## ✨ Funcionalidades Implementadas

*   **Layout Global:** Header e Footer reutilizáveis em todas as páginas, com menu responsivo (Mobile Hamburguer).
*   **Página Inicial (Home):** Carrossel de imagens interativo, seções de coleções em destaque, categorias circulares e listagem dos 8 produtos mais populares.
*   **Listagem de Produtos:** Página de busca com filtros funcionais por categoria e gênero, e contador dinâmico de resultados.
*   **Visualização do Produto:** Galeria com miniaturas, seleção de tamanhos e cores, avaliações em estrelas e cálculo de desconto.
*   **Carrinho de Compras:** Carrinho 100% funcional utilizando Context API, permitindo adicionar, remover e alterar a quantidade de itens, com cálculo de subtotal em tempo real.
*   **Telas de Autenticação:** Páginas de Login e Registro com layout fiel ao Figma (fundo em degradê e elementos flutuantes).

## 🛠️ Como rodar o projeto localmente

Para testar o projeto na sua máquina, siga os passos abaixo:

1. Clone este repositório:
```bash
git clone https://github.com/jff-trs/drip-store-frontend.git
```

2. Acesse a pasta do projeto:
```bash
cd drip-store-frontend
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

5. Abra [http://localhost:5173](http://localhost:5173) no seu navegador.
